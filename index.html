AUIBuddy — AI Campus Mentor

In progress

A RAG chatbot answering Al Akhawayn University students' questions about majors and programs from the official course catalog, instead of them digging through a PDF by hand. Actively iterating — current focus is chunk-size tuning for the catalog's tabular content and widening query expansion past "majors."

Pure vector search misses exact terms — program names, course codes — that don't have strong semantic neighbors. So retrieval is hybrid: two retrievers run in parallel and get merged by weight.

vector · MMR
BM25
vector search — k=6, fetch_k=24, λ=0.3, weight 0.6 BM25 keyword — k=6, weight 0.4

Query expansion catches phrasing the catalog uses inconsistently:

def expand_query(query): if "major" in query.lower(): query += " programs, undergraduate, Bachelor of Science, Bachelor of Arts, degrees" return query

diagnostics.py checks three pipeline stages independently of the chat loop, so a bad answer can be traced to extraction, retrieval, or generation instead of guessed at:

print(f"✅ Loaded and split PDF into {len(chunks_source)} chunks") print(f"🔍 Expanded query: {expanded_query}") print(f"✅ Retrieved {len(docs)} chunks for query: '{query}'") print(f"✅ Cosine similarity between '{q1}' and '{q2}': {cosine_sim:.4f}")

Started on local Ollama models (dolphin-phi + nomic-embed-text) for fully local inference, then migrated mid-project to the OpenAI APIAUIBuddy — git log"Switch AUIBuddy from local Ollama models to OpenAI API" — a real architecture change made during development, not a rewrite from scratch. — a real trade of local/private inference for more reliable generation quality while the retrieval side was still being tuned.
